# Análise de Dados de Saúde

Projeto desenvolvido para a disciplina de Tópicos Especiais em Software.

# Objetivo

Realizar uma análise de dados de saúde utilizando Python, comparando pacientes com e sem registro de AVC.

## Tecnologias utilizadas

- Python
- Pandas
- Matplotlib
- SQLite

## Dataset

O projeto utiliza o arquivo `Atividade2.csv`, contendo informações demográficas e indicadores de saúde.
